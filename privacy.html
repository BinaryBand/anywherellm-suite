Privacy policy

AnywhereLLM Suite. Last updated 19 October 2026.

Who this is for

AnywhereLLM Suite is a personal project run by its owner (GitHub: BinaryBand) on the owner's own server. It is used by one person, to sign in to that person's own accounts. It is not offered to the public as a service.

What it accesses

When the owner signs in to a service such as Google or GitHub, the suite receives an access token for that account, limited to the permissions the owner approved on the provider's own consent screen. For Google, those permissions are Calendar, Gmail (read, compose and send, but not permanent deletion) and Drive.

How it is used

Google account data is used only to carry out requests the owner makes to the owner's own AI agent, such as reading a calendar entry, drafting an email or finding a file. It is not used for advertising, is not sold, and is not shared with anyone else.

The suite's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Where it is stored

Sign-in tokens are stored encrypted on the owner's own AnythingLLM server, in a vault that only the suite's tools read. The agent that uses a sign-in never sees the token itself. Tokens are sent only to the provider's own API address, over https. The suite does not copy Google data to any server run by its author.

Content the agent reads on the owner's request (for example an email) is passed to the AI model provider the owner has configured for AnythingLLM, so that the model can answer. Which provider that is, and its own privacy terms, are the owner's choice.

How long and how to remove it

A sign-in is kept until the owner deletes it in the suite's Vault page. The owner can also revoke access at any time at myaccount.google.com/permissions. Deleting a sign-in or revoking access ends the suite's access to that account.

Analytics and cookies

None. This page and the home page are static and set no cookies.
